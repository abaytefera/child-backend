🏗️ Child Backend

This is the backend application for the Child Management system. Built with Node.js, Express, and MongoDB Atlas, it handles CRUD operations for child and parent data, file uploads, and integrates with Cloudinary for media storage.

🚀 Features

RESTful API for managing children and parents

File/image uploads to Cloudinary

MongoDB Atlas integration for database storage

Multi-step form support (via frontend)

Real-time updates (Socket.io support if implemented)

Validation and error handling

🛠️ Tech Stack
Layer	Technology
Backend	Node.js, Express
Database	MongoDB Atlas
File Storage	Cloudinary / Supabase
Real-time	Socket.io (optional)
Forms/API	Express Router, Multer (for uploads)
Environment	dotenv
